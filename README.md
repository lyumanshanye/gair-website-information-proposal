# GAIR Website Information Architecture Proposal

A standalone, screenshot-supported proposal for improving the information architecture and content model of
the GAIR / PLMS.ai website.

The proposal focuses on team positioning, research taxonomy, linking research with people and artifacts,
recruitment information, content governance, rollout priorities, and measurable acceptance criteria.

Open index.html directly or publish the repository with GitHub Pages. No build step or external dependency is
required.

Reference screenshots were captured from public pages on 2026-09-05 and are included only for comparative
analysis. Copyright remains with the respective websites and authors.
